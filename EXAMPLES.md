# Examples

## Ecosystem

Core message: a professional player belongs to several progressively larger collectives.

Preferred structure:

- 游戏生态
  - 游戏厂商
  - 玩家社区
  - 内容/直播平台
- 职业联赛
  - 赛事方
  - 赞助商
  - 媒体
- 俱乐部
- 职业选手

Use four concentric circles. No icons. No explanatory subtitles.

## Flow

`训练质量 → 比赛表现 → 成绩 → 职业价值`

Use four horizontal boxes. Highlight only “职业价值”.

## Quadrant

X-axis: 团队意识
Y-axis: 竞技能力

Use four short labels. Highlight the ideal quadrant with the accent color.

## Role comparison

Left: 总教练
Right: 教练
Middle: 流程监督 / 问题升级

Use 3–5 bullets per side, no decoration.
